YNC (YorNewCar) É um projeto feito em python utilizando o framework Django para auxiliar
na interface gráfica e organização dos arquivos. 

Sobre o que é a YNC ?
Consiste em um projeto de Shopcar Online (Loja virtual de carros) focado em venda 
e revenda de carros usados pelos próprios usuários. Foca principalmente em
carros usados, mas aceita perfeitamente o cadastro de carros novos.

Aprimoramentos e Adições Futuras:
- Função de criação de perfil mais detalhada
- Função para criar um perfil específico para empresas, onde empresas podem
vender seus carros também pelo site da YNC sem taxas adicionais
- Aprimoramento das conversas por chat entre usuários
- Função de gráficos interativos a respeito dos dados de vendas e carros do usuário e/ou site
